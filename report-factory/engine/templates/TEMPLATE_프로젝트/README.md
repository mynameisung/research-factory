## 입력물 체크

`00_협의/` — ①②. 프로젝트 전체 공유

- [ ] 조사개요 (`공통_시장조사개요.docx`)
- [ ] 입찰공고문/RFP (`공통_입찰공고문_RFP.docx`)
- [ ] 킥오프 회의록
- [ ] **To Know List** ← 보고서가 답해야 할 질문 목록. 오리엔테이션의 핵심 자료

`{NN}_{조사}/` — 단계 폴더에 넣는다

- [ ] 설문지 → `03_설문지/{조사}_설문지_{일자}.docx`
- [ ] 실사 URL → `/웹테스트` 인자로 (파일 아님)
- [ ] 테이블 가이드 → `07_테이블/{조사}_테이블가이드_{일자}.xlsx` — 사실상 표 목차 = 보고서 페이지 목차
- [ ] **통계표** → `07_테이블/{조사}_통계표_{일자}.xls` ← 이게 없으면 제작가이드를 못 쓴다
- [ ] 제작팀 회신본 → `11_보고서/in/{조사}_제작본_{일자}.pptx`

## 폴더

폴더 번호 = 리포 README 1절 업무 흐름의 단계 번호. 우리가 하는 단계에만 폴더가 있고, 다른 팀의 산출물은 그것을 받는 폴더에 들어온다.

```
{프로젝트}/
├─ README.md          이 파일
├─ ORIENTATION.md     ★ Step 0 오리엔테이션 결과 (본작업 전 반드시 작성)
├─ 00_협의/            ①클라이언트 협의 ②To-Know-List — 조사개요 · RFP · 회의록 · To Know List
└─ {NN}_{조사약칭}/
    ├─ 03_설문지/       ③ 설문지 .docx (정본) · ④ 온라인 구성 요청·회신
    ├─ 05_웹테스트/     ⑤ ← 업무 C   work/ (시나리오 · 덤프 · 캡처 · 세션) · out/ (findings · 수정요청서)
    ├─ 06_실사/         ⑥ 실사 현황 · 완료 통보 · 원자료
    ├─ 07_테이블/       ⑦ 테이블 가이드 · ⑧ DP 통계표 전달본 · 전처리본
    ├─ 09_제작가이드/   ⑨ ← 업무 A   work/ (questionnaire.json · tables.json · slide_facts.json · 목차.md) · out/ ({조사}_제작가이드_{일자}.xlsm · .baseline/)
    ├─ 11_보고서/       ⑩ in/ ({조사}_제작본_{일자}.pptx) · ⑪ ← 업무 B   work/ · out/ ({조사}_보고서_최종_{일자}.pptx · 검수리포트.md)
    ├─ 12_납품/         ⑫ 납품본 · 납품 기록
    ├─ _반송대장/       가이드 팀 ↔ PPT 팀 반송
    └─ _memory/         MEMORY.md · 사용자입력 · 편집기록 · 스킬실행 .jsonl
```

경로는 추측하지 않는다. `python engine/tools/paths.py projects/{프로젝트}/{NN}_{조사}` 가 역할 → 경로를 돌려준다.

**규칙**: `engine/` 은 건드리지 않는다. 이번 건에서 새로 배운 규칙만 `/회고` 로 `engine/learning/RULES.md` 에 역류시킨다.
