# {연도}_{클라이언트}_{프로젝트명}

<!-- 이 파일은 스캐폴드다. 아래 { } 를 전부 채우고 이 주석은 지운다. -->

| 항목 | 값 |
|---|---|
| 클라이언트 | {발주처} |
| 수행사 | 마크로밀엠브레인 |
| KMS No. | {번호} |
| 담당 연구원 | {이름} |
| 우리 과업 | 제작가이드 작성 (업무 A) + 보고서 완성 (업무 B) |
| 착수일 | {YYYY-MM-DD} |

---

## 조사 목록

| # | 조사 | 대상 | 표본 | 문항 | 요약·결론 | 예상 분량 | 상태 |
|---|---|---|---|---|---|---|---|
| 01 | {조사A} | {모집단 정의} | n={NN} | {NN}문항 | 필요/불필요 | ~{NN}p | ⬜ 대기 |

> 조사가 2건 이상이면 `01_조사A/` 를 복제해 `02_조사B/` 로 늘린다. 폴더명은 `{NN}_{조사약칭}`.

---

## 마감

```
{M/D} ●━ 통계표 입고
{M/D} ●━ ★ 제작가이드 제출
{M/D} ●━ ★ 제작본 회신
{M/D} ●━ ★ 최종 납품
```

**리스크**: {통계표 지연 / 배너 열 초과 / 요약표 누락 등}

---

## 입력물 체크

`00_공통/` — 프로젝트 전체 공유

- [ ] 조사개요 (`공통_시장조사개요.docx`)
- [ ] 입찰공고문/RFP (`공통_입찰공고문_RFP.docx`)
- [ ] 킥오프 회의록
- [ ] **To Know List** ← 보고서가 답해야 할 질문 목록. 오리엔테이션의 핵심 자료

`{NN}_{조사}/input/` — 조사별

- [ ] 설문지 (`{조사}_설문지_{일자}.docx`)
- [ ] 테이블 가이드 (`{조사}_테이블가이드_{일자}.xlsx`) — 사실상 표 목차 = 보고서 페이지 목차
- [ ] **통계표** (`{조사}_통계표_{일자}.xls`) ← 이게 없으면 제작가이드를 못 쓴다

## 폴더

```
{프로젝트}/
├─ README.md          이 파일
├─ ORIENTATION.md     ★ Step 0 오리엔테이션 결과 (본작업 전 반드시 작성)
├─ 00_공통/            조사개요 · RFP · 회의록 · To Know List
└─ {NN}_{조사약칭}/
    ├─ input/          설문지 · 통계표 · 원자료
    ├─ 1_제작가이드/     ← 업무 A
    │   work/          questionnaire.json · tables.json · slide_facts.json · 목차.md · 요약결론_초안.md
    │   out/           {조사}_제작가이드_{일자}.xlsm (+ _제작팀송부본) · .baseline/
    └─ 2_보고서작성/     ← 업무 B
        in/            {조사}_제작본_{일자}.pptx
        out/           {조사}_보고서_최종_{일자}.pptx · 검수리포트.md
```

**규칙**: `engine/` 은 건드리지 않는다. 이번 건에서 새로 배운 규칙만 `/회고` 로 `engine/learning/RULES.md` 에 역류시킨다.
