# 통계표 전처리 — 엑셀 리본 추가 기능

DP 원본 통계표를 제작가이드로 옮기기 전에 **인사이트를 추출하기 좋은 표로 만드는** 매크로다.
엑셀 리본에 `통계표 전처리` 탭이 하나 생기고, 왼쪽부터 순서대로 누르면 된다.

| 묶음 | 단추 | 하는 일 |
|---|---|---|
| **파일** | 가져오기 · 내보내기 · 한 번에 실행 | 통계표를 골라 작업 사본(Table + 목차 시트)으로 열고, 다 끝나면 xlsx 로 내보낸다. [한 번에 실행]은 1→2→3→4(배너 선정·데이터막대·인사이트·빈 칸 채우기)를 이어서 돌린다(삭제만은 하지 않는다) |
| **0. 설정** | 설정 | 보존 배너군·Base 하한·인사이트 기준을 한 자리에서 정한다. 저장하면 다음에 엑셀을 다시 열어도 남는다 |
| **1. 배너 선정** | 배너 선정 → 제외 배너 삭제 | 보고서에 쓸 배너군만 남기고 나머지는 회색으로 칠한다. 확인 뒤 [제외 배너 삭제]로 회색 배너를 지우고 남은 배너를 왼쪽으로 당긴다 |
| **2. 데이터막대** | 데이터 막대 표시 · 표시 지우기 | 전체 열은 파랑, 배너 열은 회색 막대 |
| **3. 인사이트** | 인사이트 표시 · 표시 지우기 | 전체 값보다 크게 높은 배너 값은 **분홍**, 크게 낮은 값은 **하늘색** 배경 |
| **4. 빈 칸** | - 로 채우기 · 빈 칸 되돌리기 | 표 몸통의 빈 칸을 `-` 로 채운다. **맨 마지막에** 누른다(팝업이 다시 알려 준다) |
| **검토** | 배너군 목록 | 배너군 이름·표 수·평균 모수를 모은다. 누르면 어느 문항 기준으로 뽑을지 고르는 팝업이 뜬다(기본 전체 선택) |
| **도움말** | 사용법 · 처음 안내 | 처음 쓰는 날 뜨는 안내를 다시 본다 |

## 1. 설치 (받아 쓰는 사람)

**`통계표전처리_설치.xlam` 파일 하나만 받으면 된다.** 다른 파일은 필요 없다.

1. 받은 파일을 **더블클릭**해서 연다.
2. 메일·슬랙으로 받았다면 엑셀이 "보호된 보기"나 노란 보안 알림 줄을 먼저 보여줄 수 있다.
   그럴 때는 **[편집 사용]**, 이어서 **[콘텐츠 사용]**(매크로 사용)을 눌러 준다 — 매크로가 든
   파일이면 어디서 받았든 늘 뜨는, 엑셀의 정상적인 확인 절차다.
3. "통계표 전처리를 추가 기능으로 설치할까요?" 팝업에서 **예**를 누른다.
4. "설치를 마쳤습니다" 안내가 뜨고 파일이 저절로 닫힌다. **이 파일은 이제 다시 열 필요가 없다** —
   엑셀을 새로 열면(또는 지금 켜진 엑셀도 다시 열면) 어떤 통계표 파일에서든 리본에
   `통계표 전처리` 탭이 보인다.

이미 설치된 상태에서 새 버전 파일을 또 더블클릭하면 "이미 설치되어 있습니다. 덮어쓸까요?"로
물어 그대로 새 버전으로 올린다.

> **배포 파일의 이름과 설치되는 이름이 다르다.** 받는 파일은 `통계표전처리_설치.xlam`(설치용),
> 실제로 엑셀에 등록되는 이름은 늘 `통계표전처리.xlam`(고정)이다. 둘을 일부러 다르게 뒀다 —
> 이미 옛 버전이 등록되어 자동으로 불려온 사람이 새 버전 파일을 열려고 할 때, 이름이 같으면
> 엑셀이 "동일한 이름을 가진 두 개의 통합 문서를 동시에 열 수 없습니다"로 **코드가 실행되기도
> 전에** 막아 버린다. 배포 파일 이름이 다르면 이 충돌 자체가 생기지 않는다. 이 설치 창은
> **배포 파일을 직접 열었을 때만** 뜬다 — 설치를 마친 뒤 엑셀이 그 추가 기능을 자동으로
> 불러올 때는 뜨지 않는다.

- 필요한 엑셀: **2010 이상**(리본 customUI14 · 데이터막대 그라데이션). 2007 은 안 된다.
- 버전이 올라가면 새 파일을 또 더블클릭하면 된다.

### 더블클릭이 막히는 환경이라면

매크로가 정책으로 완전히 잠긴 PC라면 더블클릭 설치도 못 쓴다. 그럴 때는 파일을
`%APPDATA%\Microsoft\AddIns\통계표전처리.xlam` 이름으로 직접 넣고 **파일 → 옵션 → 추가 기능 →
관리: Excel 추가 기능 → 이동** 에서 `통계표 전처리` 를 체크한다.

## 2. 쓰는 순서

1. **[가져오기]** — 통계표 파일을 고른다. Table 시트와 목차 시트만 작업 사본으로 떠서 열므로 **원본은 바뀌지 않는다.**
2. **[설정]** — 보존할 배너군 이름을 쉼표로 적는다(예: `용도, 권역, 관리 운영 방식`). 비워 두면 Base 기준만 쓴다. Base 하한(기본 30)·인사이트 기준(표준편차 2 또는 절대값 10%p)·빈 칸 취급도 여기서 정한다. 이름을 모르면 **[배너군 목록]** 을 먼저 눌러 확인한다.
3. **[배너 선정]** — 남길 배너군을 가르고 나머지를 회색으로 칠한다.
4. **[제외 배너 삭제]** — 회색 배너를 지운다. 지우기 전에 `삭제전백업_날짜` 시트를 만들어 둔다.
5. **[데이터 막대 표시]** → **[인사이트 표시]**. 기준을 바꿔 다시 보려면 [표시 지우기] 뒤 다시 누른다.
6. 다 끝났으면 **[- 로 채우기]**, 그다음 **[내보내기]**. 가져온 파일이면 `원본이름_전처리후.xlsx`, 아니면 `통계표 전처리.xlsx` 를 제안한다.

## 3. 판정 기준

### 배너 선정 — 통계표 전체를 한 번에 판정한다

| 관문 | 내용 |
|---|---|
| 보존 목록 | [설정]에 적힌 배너군은 Base 와 무관하게 남긴다. 비어 있으면 이 관문은 건너뛴다 |
| Base 하한 | 배너군 안의 항목 가운데 **절반 이상**이 Base 하한(기본 30) 이상이어야 남긴다 |

판정 단위는 표 한 장이 아니라 **통계표 전체(배너군 이름별)** 다. 어떤 표에서는 항목이 하나만
남아 30 을 넘더라도(예: A1-1 의 「기업 소유」), 통계표 전체로 볼 때 그 배너군이 미달이면 그 표에서도
회색이 되고 함께 지워진다. 표마다 다르게 판정하면 같은 배너군이 어떤 표에는 있고 어떤 표에는 없는
보고서가 되기 때문이다. 보존 목록의 오타는 「찾지 못한 이름」으로 알려 준다.

> **⚠ [보존 배너군] 은 이 엑셀 파일이 아니라 이 컴퓨터에 남는다.** 설정을 저장하면 다음에
> **다른** 통계표를 열어도 그 이름이 그대로 남아 있다. 새 설문의 배너군 이름이 이전과 다르면
> 전부 회색(미사용)으로 걸러져 배너 열이 하나도 남지 않고, 그 상태에서는 데이터막대도
> 인사이트도 전부 0으로 나온다 — 「TOP2 줄만 안 칠해진다」처럼 특정 자리만 문제로 보이기
> 쉽지만 실제로는 배너가 통째로 빠진 것이다. 통계표를 바꿀 때마다 [배너군 목록]으로 이름을
> 확인하고 [설정]의 [보존 배너군]을 새로 맞추거나 비워 둔다.

### 배너군 목록 — 어느 문항 기준으로 뽑을지 고른다

[배너군 목록]을 누르면 이 시트에 있는 문항(표) 제목이 체크리스트로 뜬다. **기본은 전체 선택**이고,
그대로 [확인]을 누르면 통계표 전체를 기준으로 배너군을 모은다. 보통은 이렇게 쓴다.

문항마다 배너 구성이 다를 수 있어, 특정 문항 하나의 배너군만 보고 싶을 때는 [전체 해제] 한 뒤
그 문항만 체크하고 [확인]을 누르면 그 문항 기준으로만 좁혀서 뽑는다. [취소]를 누르면 아무 일도
하지 않는다.

삭제는 시트 열을 통째로 지우지 않고 **표 한 장의 범위(제목 행부터)만 왼쪽으로 당긴다.**
DP 가 표마다 Base 0 인 범주를 빼서 열 위치가 표마다 다르기 때문이다. 제목 행의 테두리도 남은 폭에 맞춘다.

### 데이터막대

막대 길이의 기준은 **0~100 으로 고정**한다(열마다 최댓값에 맞추면 열끼리 견줄 수 없다).
5점 척도 평균처럼 열 최댓값이 10 이하인 표만 그 열의 범위에 맞춘다.
칠하는 범위는 Base 행 아래부터 `계` 행 직전까지이고, 요약 행(`【TOP2】`·`[5점 평균]` 등)은 뺀다.
**TOPn(TOP2·TOP3…) 요약이 있는 표는 보기 행에 막대를 넣지 않는다** — 그 표는 TOPn 만 쓰기 때문이다.

### 인사이트

`배너값 − 전체값` 이 기준을 넘으면 칠한다. 높으면 분홍, 낮으면 하늘색.

| 방식 | 기준 | 언제 쓰나 |
|---|---|---|
| 표준편차 | 그 행 배너 값들의 표준편차 σ 의 배수 (기본 2) | 행마다 흩어진 정도가 달라도 한 기준으로 훑을 때 |
| 절대값 | 전체 값과의 차이 %p (기본 10) | 기준이 눈에 보여야 설명하기 쉬울 때 |

- Base 하한에 못 미치는 열과 회색(제외) 배너는 칠하지 않는다.
- **TOPn 이 있는 표는 TOPn 줄에만** 칠한다. 보기 행은 건너뛴다.
- **데이터가 없는 칸은 0 으로 세지 않는다**(기본). 표준편차 계산에서도 뺀다. 0 으로 치고 싶으면 [설정]의 「빈 칸을 0 으로」를 켠다.
- 판정은 셀에 저장된 원값이 아니라 **표시값**(소수 1자리, 평균은 2자리)으로 한다. 보고서에 실리는 숫자와 같아야 하기 때문이다.
- 색은 조건부서식이 아니라 셀 배경색이라 데이터막대 위에 겹쳐 보인다.

### 빈 칸 `-` 채우기

`-` 는 글자라 그 칸에는 막대가 그려지지 않고 인사이트에서도 빠진다. 그래서 리본 맨 오른쪽에 두었고
[한 번에 실행]에도 넣지 않았다. 아직 막대·인사이트가 없는 시트에서 누르면 더 세게 말린다.
[빈 칸 되돌리기]로 `-` 만 골라 걷어낼 수 있다.

## 4. 표 구조를 어떻게 찾는가

열 번호를 미리 정해 두지 않는다.

* 표의 경계는 A~D열의 `Base for %` 로 찾고, 다음 표 제목 앞에서 끊는다.
* 전체 열은 배너 그룹행의 `전체` 라벨로 잡는다. 라벨 열이 두 칸인 표1(응답자 특성)도 예외 없이 처리된다.
* 배너군 경계는 그룹행에 이름이 적힌 열이다. 표마다 열 수가 달라도(실측 15~45열) 깨지지 않는다.
* 시트 전체를 한 번에 배열로 읽어 두고 판정하므로 표 276장짜리 통계표도 몇 초 안에 끝난다.

구조가 다른 시트에서는 아무것도 건드리지 않고 「표를 찾지 못했습니다」라고만 알린다. 보고서 시트가
앞에 떠 있으면 표가 있는 시트로 알아서 옮겨 간다.

## 5. 다시 굽기 (고치는 사람)

```
report-factory/engine/macros/통계표전처리/
  src/            VBA 소스 (.bas · 폼 코드 .code.txt) — 여기만 고친다
  customUI/       리본 XML
  build.ps1       소스를 모아 out/통계표전처리.xlam · out/통계표전처리_설치.xlam 으로 굽고,
                  임시 사본으로 폼·컴파일을 검증한다
  out/            결과물 — 나눠 줄 파일은 통계표전처리_설치.xlam 하나뿐이다
```

굽기 전에 엑셀에서 한 번만 켜 둘 설정: **파일 → 옵션 → 보안 센터 → 보안 센터 설정 → 매크로 설정
→ [VBA 프로젝트 개체 모델에 안전하게 액세스]**. 만드는 사람에게만 필요하다.

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```
