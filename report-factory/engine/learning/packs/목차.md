### R-029 · 목차는 MECE 여야 하고, `및` 은 MECE 위반 신호다

### R-122 · 연구부 확인용 목차는 접지 않는다 — 한 장 = 한 행
- 분류: guide / 목차
- 규칙: `part 3 목차(연구부 확인용)` 은 본문 **한 장이 한 행**이고, 열은 `챕터 / 서브 타이틀 / 문항 / 표 / 구성 및 BASE / P` 다. 여러 문항을 한 행에 묶지 않는다.
- 근거: 사용자 지시 I-030 (「결국 목차마다 그 데이터 표 매핑하는 장이야」) · LG 실측은 반대로 묶는다(`A1, A2, A3, A5, A6`)
- 왜 예시를 따르지 않나: **이 시트의 쓰임이 누락 검출**이기 때문이다(knowledge/guide/10 §2-2). 묶으면 ① 빠진 문항이 묶음 안에 숨고 ② 표 번호가 한 칸에 여러 개 들어가 「목차 ↔ 표」 대응이 1:1 로 읽히지 않는다. 예시는 **포맷의 근거이지 쓰임의 근거가 아니다**(R-028 비고와 같은 논리).
- 기계 검사: 행 수 = 본문 블록 수, `P` 가 1..N 연속, `표` 빈칸 0.
- 신뢰도: 확정
- 적용: `build_guide.write_research_toc()` · 비상주 70행
- 이력: 2026-08-22 신규

- ⚠ **표시하는 것과 혼동하지 말 것** — 표시하는 것은 **저베이스**(R-128)다. 배너 선정은 안 적고, 저베이스는 반드시 적는다.
