### 🔴 Q-001 · TA Pool 지역 배너 23개 구 → 5권역 재집계가 가능한가
- **상황**: 테이블 가이드상 TA Pool의 지역 배너가 **23개 행정구**다. 조사개요·RFP의 CBD/YBD/GBD/MBD/BBD 5권역 프레임과 맞지 않는다.
- **왜 문제인가**: 배너가 23열이면 PPT 한 장에 물리적으로 안 들어간다. 실측상 열 수 상한이 고정은 아니지만(R-057), 20열대는 어느 프로파일로도 무리다.
- **선택지**: ① DP에 권역 재집계 요청 ② 보고서에서 구를 권역으로 묶어 표기 ③ 장분리
- **매핑표 위치**: `공통_ToKnowList_서울경기건축물현황_260611.xlsx` 시트 `개요`
- **언제까지**: **통계표 입고 전.** 재집계라면 DP 작업이 필요하다
- 관련: R-056, R-057

### 🔴 Q-002 · 비상주 배너 17열이 한 장에 들어가는가, 장분리인가
- **상황**: 비상주 보고서 IN 배너가 **표당 6~17열**(17열이 61표로 최빈)이다.
- **왜 문제인가**: 열 너비는 제작팀이 슬라이드마다 다시 잡으므로 상한을 우리가 못박을 수 없다(R-057). 제작팀·연구원의 판단이 필요하다.
- **선택지**: ① 열폭 축소로 한 장 ② 장분리 ③ 배너군을 더 줄인다
- **언제까지**: **첫 5장 리뷰 때** 함께 확정
- 관련: R-057, 제작팀 메모 `장분리`

### 🟡 Q-003 · 제작가이드 제출 시 `검수 실행` 버튼 통과가 필수인가

- 관련: R-038

### 🔴 Q-MAP-01 · 장분리 임계는 몇 열인가 (R-089)
- **상황**: 배너 27열 → 2장(4건), 22열 → 1장(1건). LG 본문 82블록에서 **분리/비분리 판정 자체는 반례가 없다**(27열 4건 전부 2장, 22열 이하 78건 전부 1장). 그런데 임계의 정확한 위치는 `[23, 27]` 구간으로만 좁혀진다.
- **왜 문제인가**: 현재 값 `22` 는 관측된 최대 비분리 열 수를 그대로 쓴 것이다. 다음 조사에서 24열짜리가 1장으로 나오면 우리가 없는 장을 만든다. 반대로 26열을 안 나누면 한 장을 통째로 빠뜨린다.

- **선택지**: ① 열 수 임계 유지 ② `(32.0 − 라벨열 폭) / 최소열폭 1.0cm` 로 계산 ③ 제작팀에 직접 확인
- **확인할 것**: ① 열폭 1.0cm 가 하한인가 ② 장을 나눌 때 마지막 배너군만 떼는 게 맞는가, 3장 이상도 있는가
- **언제까지**: **첫 5장 리뷰 때** — Q-002 와 같은 자리에서 답이 나온다
- 관련: R-057, R-089, Q-001, Q-002, 제작팀 메모 `장분리`

### 🟡 Q-BASE-01 · 장분리 2장째의 Base 정의가 달라질 수 있는가 (R-089)
- **상황**: `deck:LG s84`(C3 2장째)만 1장째와 Base 표기가 다르다 — `중복` ↔ `3개 문항 응답`.
- **두 해석**:
  ① **복붙 오기**(현재 채택) — s84 의 표 전체 열이 (100)인데 `3개 문항 응답` 은 base 300 표기다. 이웃 s85·s86 이 그 문자열을 쓴다 → GOLDEN_SET §5-h-1
  ② **배너군 유래** — s84 의 배너군은 `C2 1+2+3순위 시나리오별` 이고 그 15열의 n 합이 정확히 **300** 이다. "배너 자체가 3문항 응답" 이라는 뜻일 수 있다
- **왜 ②를 못 채택하나**: 같은 구조인 `s88`(C4 2장째)은 배너군이 `C2 1순위`(n 합 100)이고 표기가 `중복` 이다. ②가 맞다면 s82(n 합 300, `3개 문항 응답`)와 s88 은 설명되지만, **결정적 관찰은 s84 1건뿐**이다.
- **확인할 것**: 다른 조사에서 문항 파생 배너군을 쓸 때 Base 표기를 어떻게 적는가
- 관련: R-089, R-013, GOLDEN_SET §5-h-1

### 🟡 Q-TOPTEXT-01 · A10 의 TOP2 / BOT2 는 보기번호 기준인가 의미 기준인가 (R-114)
- **상황**: 가이드는 `【TOP2】=40.0`(보기 3·4), 제작본은 `TOP2(%)=60.0`(보기 1·2)으로 **정반대**다. 제작팀 메모가 `Data (TOP2/BOT2) 수정` 으로 붙어 있다.
