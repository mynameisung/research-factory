# 21. 멘트 보강 【업무 B】

제작본에 멘트가 비어 있는 슬라이드를 채운다.

**원칙: 이 작업이 남아 있으면 업무 A를 덜 한 것이다.**

> "이거를 후작업하지 말고 제작 가이드 할 때 멘트를 같이 쓰면 걔네가 멘트도 넣어줘요." (녹취 15:14)
> "그게 더 빠르긴 해요." (15:20)

실측이 증명한다:

| 덱 | 가이드의 멘트 | 제작팀 메모 |
|---|---|---|
| **LG** | 93블록 중 **9블록 / 25줄**만 작성 | **71장에 메모** |
| **SKEE** | 109블록 중 **77블록 / 147줄** 작성 | **0장** |

멘트를 미리 쓴 쪽은 후작업이 없었다.

---

## 1. 언제 필요한가

| 상황 | 처리 |
|---|---|
| 제작가이드에 멘트를 다 썼다 | **이 문서는 건너뛴다.** 제작팀이 이미 넣어 왔다 |
| 일부만 썼다 | 빈 슬라이드만 채운다 |
| 아예 안 썼다 | 전량 작성 — 사실상 업무 A의 멘트 작업을 여기서 하는 것 |
| 제작본에 오타·수치 오류가 있다 | 고친다 (→ `report/22`) |

---

## 2. 멘트 슬롯 찾기 — ★ placeholder idx 를 믿지 마라

멘트는 본문 슬라이드 상단의 placeholder 에 들어간다. 그런데 **덱마다 idx 가 다르다.**

| 덱 | sub_title | top_ment |
|---|---|---|
| SKEE | idx **13** | idx **12** |
| LG | idx **12** (T=2.62) | idx **13** (T=3.42, 79장 전부 비어 있음) |

**79장 전부 반대다.** idx 로 판정하면 서브타이틀 자리에 멘트를 쓰게 된다.

### 위치로 판정한다
```
같은 layout 의 본문 슬라이드를 모아
placeholder 들을 top_cm 오름차순으로 정렬 →
  위쪽(작은 top)  = sub_title
  아래쪽(큰 top)  = top_ment
```
LG 실측: sub_title T=2.62 / ment T=3.42.
덱 전체에서 한 번 판정하고 전 슬라이드에 같은 매핑을 쓴다 (슬라이드마다 다르지 않다).

---

## 3. 작성 규칙

**`guide/13` 을 그대로 따른다.** 여기서 새 규칙을 만들지 않는다.

요약:
- 개조식 `~임 / ~함 / ~순임`, **마침표 없음**, 보기 라벨은 `'…'`
- 1행 = 전체 값 (보기 10개면 3개, 적으면 1~2개)
- 2행 = 배너 튀는 값 (없으면 생략)
- 패턴 A(척도) / B(배너) / C(다항목·순위) / D(초소표본, 퍼센트 없음)
- 수준어 사다리: <50 미흡 / 50%대 보통 / 60%대 약간 긍정 / 70%대 긍정 / ≥80 우수
- % 1자리, 평균·NPS 2자리

---

## 4. 값의 출처는 언제나 통계표다

**제작본 차트에서 값을 읽어 멘트를 쓰지 않는다.**

이유:
1. 차트 값은 이미 반올림·가공됐을 수 있다
2. 제작팀이 계열을 쪼개거나 더미를 넣은 경우가 있다 (`do not know`, `열2` 등)
3. 제작본 자체에 오류가 있다 — LG s6 `n=1,000` (실제 100)

```
통계표 → 서식 적용 후 값 → 멘트
                ↑
        제작본은 여기 안 들어온다
```

> "데이터를 기반으로 하는 거니까 통계표를 보고, 굳이 이 보고서를 보고 할 필요는 없어요." (15:23)

제작본은 **어느 슬라이드에 무엇이 비었는지**를 알려줄 뿐이다.

---

## 5. 배너 선별 — 유의차

`guide/13 §4` 의 정량화 방안을 그대로 쓴다.

```
1. 배너 셀 vs 전체 2-proportion z-test 전수 계산
2. |배너값 − 전체값| 랭킹
3. |z| ≥ 2 이면서 차이가 큰 상위 1~2개만 채택
4. 배너군마다 최대 1개
5. 높은 쪽이 없으면 낮은 쪽
6. 아무것도 유의하지 않으면 2행 생략
7. n<30 배너 셀은 후보에서 제외
```

n=500 기준 2σ ≈ **4.4%p**. 다만 이건 하한이지 채택 기준이 아니다.
> "그러면 너무 읽을 게 많아져서 안 돼." (16:49)

**배너 IN 범위 안에서만 고른다.** 절단선 밖은 아무리 유의해도 쓰지 않는다.
> "이 뒤에는 아무리 유의미해도 안 쓸 거예요." (08:24)

⚠ 배너 열 수는 표마다 다르다 (비상주 실측 IN 6~17열). **그룹명으로 판정한다.**

---

## 6. 슬라이드 유형별 멘트

| 유형 | 줄 수 | 내용 |
|---|---|---|
| 본문 (기본형) | 2 | 전체값 상위 N개 → 배너 튀는 값 |
| 본문 (척도) | 2 | `{항목}은 NN.N%(TOP2 기준)로 {수준어} 수준임` → 배너 |
| 본문 (순위) | 1~2 | 1~N순위 기준 상위 3개 → 배너 |
| 본문 (n<30) | 1 | 패턴 D, **퍼센트 없이** |
| 요약 | 3 | 대표 지표 → 높은 것/낮은 것 대비 → 그룹 수준 요약 |
| 결론 | — | 멘트가 아니라 제언 본문. `guide/14 §6` |
