# 15. 한국어 문장 지침 — fluent-korean 을 제작가이드 문장에 적용하는 방법

출처: https://github.com/snflkd/fluent-korean (MIT, snflkd). Claude Code output-style 로 만들어진 「의미가 명확한 한국어」 지침이다.
사용자 지시(2026-08-23): 이 지침을 적용한 뒤 제작가이드 산출물을 다시 비교한다. 서브에이전트는 output-style 을 물려받지
않으므로, 문장 담당(guide-body-ment · guide-summary · guide-conclusion)은 **이 문서를 읽고** 문장을 쓴다.

## 0. 우선순위 — 하우스 규칙이 위, 이 지침은 그 안에서

이 지침은 **문장 안쪽**(조사·어미·성분·어휘 선택)을 다듬는 규칙이다. 다음 하우스 규칙과 부딪히면 하우스가 이긴다.

| 하우스 규칙 | 지침과의 관계 |
|---|---|
| 개조식 ㅁ받침 종결(~임/~함/~순임/~편임), 마침표 없음 — 13_멘트-작성규칙 · R-132 | 지침 「문장 단위 2」(서술어+종결어미로 끝맺기)의 **예외**. 지침 자체가 「헤더와 목록에는 강제하지 않는다」「별도 지침이 있는 산출물엔 적용하지 않는다」고 둔다. 멘트·요약 해석·결론 본문은 개조식 목록이다 |
| 보기명(라벨) 원문 그대로 작은따옴표 · 수치는 display 그대로 · 「~별로 보면」 정형 · 수준어 사다리 · ≤60자 | 지침 「구 단위 2·3」(한자어·비유 어휘)보다 우선. 라벨은 고치지 않는다 |
| 요약 헤드라인 ≤40자·수치 없음·판단문(R-130) · 결론 제목은 판단 한 문장(R-126) | 길이 상한 안에서 지침을 적용한다. **측정 대상어(만족도·의향·동의 수준)와 기준 한정구(「(1~3순위 기준)」「(TOP2 기준)」)는 상한보다 우선**한다 — 상한을 넘기면 §1-9 의 순서로 줄인다(A/B 실측 2026-08-23: seq 13 「만족도」 생략·순위형 8장 한정구 탈락이 부작용이었다) |
| 목차·서브 타이틀 = 한 어절 명사구(R-028) | 지침 미적용(명사구가 규칙) |

## 1. 적용하는 조항 (멘트 · 요약 해석 · 결론 본문 · 결론 제목 · 요약 헤드라인)

원문 조항을 제작가이드 문장에 맞게 옮긴다. 괄호 안은 우리 산출물에서의 예.

1. **의미 있는 문장 성분을 생략하지 않는다.** 주어·대상·기준이 빠져 독자가 표를 봐야만 뜻이 서는 문장을 쓰지 않는다.
   「만족도는 74.4%(TOP2 기준)로 긍정적인 수준임」 → 무엇의 만족도인지 문두에 둔다: 「재무행정 관리 만족도는 …」.
   연작 장표(C2_1)~7) 등)는 항목명을 문두에 넣는다(「지원 방식은」 → 「임대차 계약 지원 방식은」).
2. **관형격 「~의」를 겹쳐 쓰지 않는다.** 「도심권의 '거의 만실'의 응답」 → 「도심권에서 '거의 만실' 응답이」. 단 하우스 정형
   「{배너}의 '{보기}' 응답이 상대적으로 높음」은 한 번의 「의」라 그대로 둔다.
3. **조사와 어미를 생략하지 않는다.** 「위탁 경험군 현 지불액 수준, 직접 관리군 진입형」처럼 조사를 뺀 나열을 쓰지 않는다 →
   「위탁 경험군에는 현 지불액 수준으로, 직접 관리군에는 진입형으로」. 부사·보조사(「오히려」「도」「만」)로 관계를 드러낸다.
4. **구체적 한자어 + 자연스러운 통사.** 「값은 한 줄로 놓을 수 없다」 같은 비유는 제목에서만 허용하고, 본문에서는 「가격을 단일
   수준으로 제시할 수 없음」처럼 뜻이 하나로 읽히는 어휘를 쓴다.
5. **비유적 어휘로 일반 명사·동사를 대체하지 않는다.** 「만족이 뒤에 있음」 → 「만족도가 낮음」, 「내려앉음」 → 「낮아짐/떨어짐」,
   「약한 고리」 → 「취약한 요소」, 「낙차」 → 「격차」, 「관망함」은 통용 관용어라 허용. 헤드라인의 판단문도 같은 기준 —
   **비유로 짧게 만든 헤드라인은 뜻이 둘로 읽힐 수 있으므로 일반 어휘로 바꾼다**(R-130 의 「수치 없는 판단문」은 유지).
6. **엠대시(—)를 쓰지 않는다.** 결론 제목 「진입할 자리는 있다 — 부족한 것은 믿을 근거다」 → 두 문장 또는 쉼표·접속어로.
7. **사용자 메시지의 어조를 모방하지 않는다.** 대화의 구어체가 산출물에 스며들지 않게 한다.
8. **고유명사·기술 용어**는 통용 번역어를 우선(「레퍼런스」→「시공 실적」처럼 하우스가 이미 쓰는 말이 있으면 그것).
9. **길이 상한과 충돌할 때 줄이는 순서** (A vs A2 실측에서 고정)
   ① 2·3위 나열을 절단한다(보기가 셋 이상 남으면 「등의 순임」의 「등」은 유지) → ② 척도 연작(A8 등)은 항목명을 「…등 ○○ 관리」로 축약한다
   (장 제목이 원문 라벨을 담으므로) → ③ 방향이 다른 배너 두 건은 줄을 나누고 줄마다 측정 대상을 반복한다.
   멘트는 장당 **3줄 이하**. 긴 라벨(20자 이상)은 「X가 NN.N%로 가장 높음 / 다음으로 Y가 NN.N%임」 2줄까지만, 3위는 절단.
   동률(ties)은 「이어 'A', 'B'가 20.7%로 동률임」으로 묶고 「등」으로 뭉개지 않는다. 배너 줄의 「응답이」는 성분이라 빼지 않고, 배너명에 따옴표를 씌우지 않는다.
   요약 헤드라인은 비유만 치환하고 크기 어휘·대비 구조는 보존한다(A 가 비유 없이 40자 안이면 주어만 보강). 결론 제목은 30자 이하.

### 비유 치환표 (§1-5 의 실측)
「뒤에 있음」→「가장 낮음/하위권임」 · 「내려앉음」→「떨어짐」 · 「약한 고리」→「취약함」 · 「낙차」→「격차」 · 「도입에 가까움」→「도입 의향이 높음」 ·
「꺾이고」→「낮아지고」 · 「몰림」→(사실 서술로) · 「팔 것·갈 곳·이름부터 알린다」→「주력 상품·우선 대상·브랜드 인지도부터 높인다」.
**치환하지 않는 것**: 「절반 아래」「과반」「최고/최저」처럼 숫자 없이 크기를 전하는 일반 어휘(비유가 아니다). 「~으므로」는 인과일 때만.

## 2. 적용하지 않는 조항

- 문장 단위 2(서술어+종결어미 완결) — 개조식 산출물 전체. 단 **조사개요·Cover 산문**과 결론 「레이아웃:」 지시문(「…구성 부탁드립니다.」)은 완결문이므로 적용.
- 구 단위 2 의 「한자어 적극 활용」은 **보기명·문항 문구를 바꾸는 데 쓰지 않는다**(원문 대조 규칙이 위).

## 3. 게이트

기계 게이트(`verify.py --mode ments|summary|conclusion`)는 바뀌지 않는다 — 이 지침은 게이트 안에서 문장을 고르는 기준이다.
검토관(guide-summary-reviewer · guide-adversary)은 렌즈 「문체·가독성」에서 위 1~8 위반을 findings 로 올린다.

## 4. 실측 (2026-08-23, 비상주) — 부분 채택
