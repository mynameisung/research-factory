멘트 = 슬라이드 상단에 들어가는 해석 문장. 제작가이드의 `Data` 라벨 아래에 미리 써 둔다.

> "이거를 후작업하지 말고 제작 가이드 할 때 멘트를 같이 쓰면 걔네가 멘트도 넣어줘요." (녹취 15:14)

코퍼스: `예시_제작가이드_SKEE만족도_추가.xlsm!본문` 의 멘트 **147줄 / 77블록** (LG는 25줄 / 9블록뿐이라 참고만).

## 1. 작성 절차

```
① 정렬        전체 값 내림차순. 시계열·고정 보기순서면 원순서 유지
② 1행         전체 값을 읽는다. 보기 10개면 3개, 적으면 1~2개
③ 2행         배너에서 전체 대비 튀는 값만. 없으면 생략
④ 소수점      % 1자리 / 평균·NPS 2자리
```

### ① 정렬
> "이 전체 값 기준으로 내림 차순을 정렬을 하거든요. 근데 그게 시계열이 아니면 내림 차순을 정렬을 해요." (13:25)
> "순서가 정해져 있으면 그 순서대로 가고 그렇지 않은 것들은 이 크기대로 내림차순을 해요." (13:54)

실무상 **DP가 이미 정렬해서 준다** — 중복응답·순위 표는 전체 값 내림차순, 단일선택·척도 표는 보기번호 오름차순.
그러니 통계표 순서를 그대로 따르면 되고, 예외는 **척도**다. 척도는 보기번호 순으로 오지만 멘트는 `【TOP2】` 값으로 읽는다.

### ② 1행 — 전체 값
> "이 전체 값을 기준으로 이 보기 개수에 따라 달라. 보기 개수가 한 10개가 되면 한 3개 읽고 보기 개수가 몇 개 없으면 한두 개만 읽어도 돼요."
> "뭐가 제일 높고 뭐가 몇 퍼센트로 제일 높고 뭐가 몇 퍼센트 뭐가 몇 퍼센트 순으로 이렇게 하고" (14:01)

| 보기 수 | 읽는 개수 |
|---|---|
| ~4개 | 1~2 |
| 5~9개 | 2~3 |
| 10개 이상 | 3 |

### ③ 2행 — 배너 튀는 값
> "첫 번째 배너 두 번째 배너 세 번째 배너에서 각각 진짜 이 얘에 비해서 너무 튀는 값 있잖아요. (…) 이런 걸 읽어주면 돼."
> "그럼 거기서 제일 높은 애들을 하나 두 개씩 읽어주면 돼. 아니면 반대로 그렇게 제일 높은 게 없고 오히려 낮은 게 있어. 그럼 낮은 걸 읽어주면 돼."
> "없으면 안 읽어도 돼. 쟤는 필수적인 건 아니야." (14:21~15:00)

## 2. 문장 패턴 A~D

전부 **개조식**이다 — `~임 / ~함 / ~순임 / ~생각함`. **마침표를 찍지 않는다.** 보기 라벨은 작은따옴표 `'…'`.

### A · 척도 전체값
```
{항목}은 {NN.N}%(TOP2 기준)로 {수준어} 수준임
```
실측 (SKEE C720): `계약전 사전 서비스 만족도는 82.1%(TOP2 기준)로 우수한 수준임`
실측 (SKEE C1032): `공정관리 수준 만족도는 82.1%(TOP2 기준)로 우수한 수준임`

**A′ · 사람 주어형** — "~라고 응답한 {응답자군}는"
```
{항목}이 높다고 응답한 {응답자군}는 {NN.N}%(TOP2 기준)로 {수준어} 수준임
```
실측 (SKEE C1555): `안전관리자의 역량 수준이 높다고 응답한 근무자는 81.0%(TOP2 기준)로 우수한 수준임`

**A″ · NPS** — 소수 2자리
실측 (SKEE C1974): `추천 의향은 -17.86점(NPS 점수)으로 미흡한 수준임`

**A‴ · 복문** — 두 지표를 한 줄에
실측 (SKEE C163): `전반적 만족도는 71.4%로 긍정적인 수준이며, 향후 이용 의향 역시 71.4%로 긍정적인 수준임`
(원본에는 `761.4%` 오타가 있다 → `report/22` 체크리스트)

### B · 배너
```
{배너1}별로 보면 {셀}, {배너2}별로 보면 {셀}의 {지표}가 상대적으로 높음
```
실측 (SKEE C721): `소속별로 보면 SK플라즈마, 직위별로 보면 임원급의 만족도 평가가 상대적으로 높음`
실측 (SKEE C1462): `소속별로 보면 SK플라즈마, 직위별로 보면 임원급이 상대적으로 현장소장의 역량 수준이 높다고 생각함`

**B′ · 배너 + 보기 지정**
```
{배너}별로 보면 상대적으로 {셀}의 '{보기}' {지표}가 높은 편임
```
실측 (SKEE C763): `소속별로 보면 상대적으로 SK IE&S의 '소통 원활' 만족도가 높은 편임`
실측 (SKEE C1182): `소속별로 보면 SK 가스의 원인으로는 '설계 오류'가 높은 편임`

### C · 다항목 / 순위 / 복수응답
```
{맥락} 이유는 'X'가 {NN.N}%로 가장 높고, 'Y'({NN.N}%), 'Z'({NN.N}%) 등의 순임
```
실측 (SKEE C762): `계약 전 사전 서비스에 대해 만족으로 평가한 이유는 '소통 원활'이 69.6%로 가장 높고, '타당성 조사 적정성 우수'(17.4%), '프로젝트 총비용 산출 정확도 우수'(8.7%) 등의 순임`

변형: `가장 높고,` ↔ `가장 높으며,` (둘 다 실측. 후자가 더 많다)
동률이면 묶는다 — `'A', 'B'(33.3%) 등의 순임`

### D · 초소표본 / 값이 무의미할 때
```
{맥락} 이유는 'X'가 있음
```
실측 (SKEE C1115): `당사의 안전관리 수준에 대해 불만족 및 보통으로 평가한 이유는 '관리감독자의 안전관리 의식 부족'이 있음`
실측 (SKEE C1265): `사후관리에 대해 불만족 및 보통으로 평가한 이유는 '기술지원 지연 또는 부족', '하자보수 관련 후속관리 부재'(50.0%)가 있음`

**★ 퍼센트를 쓰지 않는다.** n이 1~2명이면 100%·50% 같은 수치가 오해를 부른다.
적용 기준: `Base for %` 가 n≤2 이거나, 보기별 응답이 1건씩뿐일 때.

## 3. 수준어 사다리

> 척도 문항에 대해 점수 ①, ②의 비율을 합산하여 Bottom2로 , ④, ⑤의 비율을 합산하여 Top2로 정의하였음,
> 척도 문항 수준에 대해 50.0% 미만은 미흡, 50.0%대는 보통, 60%대는 약간 긍정, 70%대는 긍정, 80이상은 우수로 해석하였음
> — SKEE 본문 D60:D61 (조사 개요 슬라이드에 문서로 박아 둔 해석 기준)

| Top2 | 형용사 | 어미 | 실측 검증 |
|---|---|---|---|
| **< 50.0%** | 미흡 | `미흡한 수준임` | 14.3 / 39.3 / 46.4 |
| **50.0%대** | 보통 | `보통 수준임` | 50.0 / 57.1 / 59.1 |
| **60%대** | 약간 긍정 | `약간 긍정적인 수준임` | 60.7 / 64.3 / 67.9 / 69.6 |
| **70%대** | 긍정 | `긍정적인 수준임` | 71.4 / 75.0 / 76.2 / 78.6 |
| **≥ 80%** | 우수 | `우수한 수준임` | 81.0 / 82.1 / 85.7 / 92.6 / 96.4 |

SKEE 코퍼스 전량(척도 멘트 40여 줄)에서 **예외 0건**. 경계값 처리도 그대로다 — 50.0 → 보통, 80.0 → 우수.

**조사 개요 슬라이드에 이 기준을 문서로 넣는다.** 그래야 보고서 독자가 형용사를 검증할 수 있다.

## 4. 유의차 — 2σ 기준과 실무의 간극

### 원칙
> "그 투 시그마 기준으로 500일 때는 몇 퍼센트 차이가 나야지 유의미하다." / "4.4% 이상 차이가 나면 읽는다고 하거든요." (16:04~16:34)

n=500, p≈0.5 기준 2σ ≈ 4.4%p.

### 실무
> "근데 이거 안 중요해요. 그냥 딱 봤을 때 튀는 값을 읽으면 되는데"
> "그러면 너무 읽을 게 많아져서 안 돼. (…) 얘 튀긴 튀죠. 근데 얘가 훨씬 튀잖아요. 그럼 도심 것만 읽으면 돼. 얘는 생략해도 돼."
> "이런 식으로 기준이 명확하지 않아서 이걸 안 줘도 되는 거예요." (16:41~17:17)
> "어 그냥 바이브대로 하면 돼." (17:17)

즉 **4.4%p 는 하한이지 채택 기준이 아니다.** 전부 적용하면 읽을 게 너무 많아진다.

### 정량화 방안
```
1. 배너 셀 vs 전체 로 2-proportion z-test 를 전 셀에 대해 계산
2. |배너값 − 전체값| 로 랭킹
3. 유의(|z| ≥ 2) 하면서 차이가 가장 큰 상위 1~2개만 채택
4. 배너군마다 최대 1개 (군을 넘겨 2개 이상 뽑지 않는다)
5. 높은 쪽이 없으면 낮은 쪽을 읽는다
6. 아무것도 유의하지 않으면 2행을 생략한다
```

n<30 배너 셀은 후보에서 제외한다 (`*Too small base(n<30)`).

이 임계값은 **학습 대상**이다. 사람이 우리 멘트에서 배너를 지우거나 다른 걸 넣으면
그 diff가 곧 임계 조정 신호다 (`engine/learning/observations.jsonl`).

## 5. 배치와 분량

- `Data` 라벨 **아래 행부터**, 라벨 없이 값 열에 이어 쓴다. 1행 = 1문장
- 관행은 **2줄** (전체값 1줄 + 배너 1줄). 요약 장표는 3줄까지 (SKEE C163:C165)
- 위치는 엄격하지 않다 — "제작팀이 직접 하는 거라 위치는 진짜 상관없긴 해요" (24:23)
- 줄 수 제한도 없다 — "세 줄 네 줄도 상관없긴 해요" (24:18)

SKEE 실측: 77블록에 멘트 147줄 = 블록당 평균 1.9줄.

## 평균이 있으면 **독립 문장으로 먼저 말한다** (R-193 · 2026-08-28 개정)

평균 행이 있는 장표는 멘트에 평균을 반드시 싣되, **한 문장에는 통계량을 하나만** 담는다.
평균과 순위(또는 TOP2)를 「~이며,」로 한 문장에 잇는 종전 문형은 폐기했다(사용자 지시 2026-08-28).

```
수치형(개·층·만원 …)          척도형(점 · TOP2 수준어)
{주어}는 평균 {값}{단위}임      {주어}는 {NN.N}%(TOP2 기준)로 {수준어} 수준임
'{1위}'가 {NN.N}%로 가장 높고,  평균은 {N.NN}점임
'{2위}'({NN.N}%) 등의 순임      {배너 줄}
{배너 줄}
```

- **대표 통계량 문장이 앞선다** — 수치형은 평균이 대표값이라 첫 줄, 척도형은 TOP2 수준어
  판정이 대표라 첫 줄이고 평균은 둘째 줄 `평균은 {N.NN}점임` 으로 내린다.
- 순위는 순위끼리 한 문장 — 1·2위를 「가장 높고, ~ 등의 순임」으로 묶는다.
  60자를 넘을 때만 「다음으로 'Y'가 NN.N%임」(K-01) 둘째 줄로 가른다.
- 문항명 자체에 평균이 들어 있으면(「월 평균 지불 비용」) 겹쳐 적지 않는다 —
  SH 코퍼스 「평균 이용 금액은 2,763만원임」 문형. **이 유형은 단어 검색이 평균 누락을
  못 잡는 사각지대다** — 평균 행 존재 ↔ 평균 값 인용을 값으로 대조하라(비상주 seq24 실측).
- 값과 자릿수는 **표의 평균 행 그대로**(2자리). 줄이려고 깎지 않는다.
  단위는 `Base/Unit` 의 `Unit: %, 개월` 에서 가져온다.
- 혼합 문형(`평균 {값}{단위}이며, …%`)은 검수 `style_gate` K-16 이 경고로 잡는다.

폐기한 종전 문형(한옥 코퍼스 「평균 1억 4265만원이며, '2억원'이 46.4%로 가장 많음」)은
근거였던 코퍼스가 있어도 **사용자 확정 지시가 우선**한다는 선례로 남긴다.

### 왜 빠지기 쉬운가

평균 행에는 `그래프 상단 Text` 가 붙어 **차트 위에 따로** 표시된다. 표만 보고 멘트를 쓰면 평균을 지나친다.

## 배너 해석은 쓰지 않는다 (R-194)

「건물 소유 형태별로 보면 기업 소유의 … 응답이 상대적으로 낮음」 같은 **배너 비교 줄을 쓰지 않는다.**
멘트는 전체 열 기준으로만 쓴다.

배너 셀의 n 이 대부분 30 미만인 조사에서는 「상대적으로 낮음」이 응답 한두 건으로 뒤집힌다.
**배너가 유의차 판정에 쓰이는 조사(셀 n≥30)에서는 이 규칙을 적용하지 않는다** — 조사 성격을 먼저 판정한다.
