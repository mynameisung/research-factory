# research-factory 0.5.0 — 2026-09-18

설문지를 만들어 주는 스킬이 새로 생겼고, 도구 이름이 **research-factory** 로 바뀌었습니다. 업그레이드한 뒤에는 Claude 창을 한 번 닫았다가 다시 열어 주세요.

## 무엇을 했나

- 도구 이름이 report-factory 에서 **research-factory** 로 바뀌었습니다. 보고서만이 아니라 설문지·웹테스트까지 맡게 되어서 이름을 넓혔습니다. 내 조사 자료는 그대로 있고, 업그레이드 한 번이면 자동으로 정리됩니다.
- **설문지 작성 스킬**이 추가되었습니다. 구조화 엑셀을 주면 엠브레인 양식 설문지가 나옵니다.
- 설문지를 읽는 눈이 좋아졌습니다. 표 안에 들어 있는 보기, 0 이나 1 부터 시작하는 숫자 척도, 「최소 N개, 최대 M개 선택」 같은 문항을 전에는 잘못 읽거나 놓쳤는데 이제 제대로 읽습니다. 웹테스트와 제작가이드가 이 문항들을 더 정확하게 봅니다.
- 개선공유가 끝까지 갑니다. 전에는 PC 에 따라 공유가 중간에 멈추는 일이 있었는데, 이제 필요한 것을 먼저 확인하고 끝까지 올립니다.

## 추가된 스킬 1

**/설문지작성**  설문지 작성 : 구조화 엑셀을 받았을 때 설문지 초안을 만들 수 있는 스킬

* 구조화 파일(TKL 이 있으면 그것까지)만 주면 엠브레인 양식 설문지(.docx)가 나옴
* 문항 문장·보기·척도·BASE/PROG·파이핑을 하우스 규칙대로 정해 주는 점이 차별화됨
* 구조화 대비 빠진 문항, 틀린 분기, 겹치는 질문을 검수하고 반증 검토까지 거쳐서 실사팀에 그대로 넘길 수 있는 품질을 냄
* 결과는 조사 폴더의 `03_설문지/` 에 남음

## 무엇이 가능해졌나

- 구조화 파일을 받은 날 설문지 초안까지 한 번에 갈 수 있습니다.
- 표 보기와 숫자 척도가 많은 설문지도 웹테스트가 놓치지 않고 대조합니다.
- 내가 다듬은 요령을 개선공유로 올리면 관리자에게 확실히 도착합니다.

## 한번 써보세요

1. 구조화 엑셀을 조사 폴더에 넣습니다.
2. 채팅창에 이렇게 입력합니다.

```
/설문지작성 <구조화 파일 경로>
```

3. 설문지 .docx 와 검수 결과가 `03_설문지/` 에 생깁니다. 검수에서 잡힌 것부터 보면 됩니다.

## 주의할 점

- 업그레이드한 뒤 Claude 창을 한 번 닫고 다시 여세요. 새 이름의 폴더로 스킬이 붙습니다.
- 엑셀 파일이 열려 있으면 자료 정리가 미뤄집니다. 「열린 파일 때문에 못 옮김」이 뜨면 엑셀을 닫고 스킬을 다시 부르면 됩니다.
