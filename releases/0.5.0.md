# research-factory 0.5.0 — 2026-09-18

설문지를 만들어 주는 스킬이 생겼습니다. 업그레이드 뒤에는 Claude 창을 한 번 닫았다가 다시 여세요.

## 무엇을 했나

- 도구 이름이 **research-factory** 로 바뀌었습니다. 내 조사 자료는 그대로입니다.
- **설문지 작성 스킬**이 생겼습니다.
- 설문지를 더 정확하게 읽습니다. 표 안의 보기, 숫자 척도, 「최소 N개 선택」을 놓치지 않습니다.

## 추가된 스킬 1

**/설문지작성**  설문지 작성 : 구조화 엑셀을 받았을 때 설문지 초안을 만드는 스킬

* 구조화 파일만 주면 엠브레인 양식 설문지(.docx)가 나옴
* 문항·보기·척도·분기를 하우스 규칙대로 정해 주는 점이 차별화됨
* 빠진 문항과 틀린 분기를 검수해서 실사팀에 바로 넘길 수 있는 품질을 냄

## 무엇이 가능해졌나

- 구조화 파일을 받은 날 설문지 초안까지 한 번에 갑니다.
- 표 보기가 많은 설문지도 웹테스트가 놓치지 않습니다.

## 한번 써보세요

채팅창에 이렇게 입력합니다.

```
/설문지작성 <구조화 파일 경로>
```

결과는 조사 폴더의 `03_설문지/` 에 생깁니다.
