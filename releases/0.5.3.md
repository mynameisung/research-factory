# research-factory 0.5.3 — 2026-10-15

스킬 두 개가 새로 들어왔습니다 — 통계표 검수(/테이블검수)와 PDF 보고서형 웹테스트(/웹테스트-PDF).

## 무엇을 했나

- 실사 뒤 받은 통계표를 설문지·테이블가이드와 맞대어 검수하는 스킬을 추가했습니다.
- 설문 Word와 테스트 링크만으로 웹테스트를 돌려 PDF 보고서를 내는 스킬을 추가했습니다.

## 추가된 스킬 1

**/테이블검수**  테이블 검수 : DP실에서 통계표를 받았을 때 쓸 수 있는 스킬

* 쿼터·전 문항 Base·로직·코드·문번·보기 누락과 문구를 한 번에 대조함
* 정답 기준을 설문지에 두고 가이드 오기까지 잡아냄
* 0건이라 빠진 보기는 이슈가 아니라 따로 목록으로 남김
* 결과는 검수 엑셀로 남음

## 추가된 스킬 2

**/웹테스트-PDF**  웹테스트 PDF : 조사 폴더 없이 빨리 웹테스트를 돌리고 PDF로 받고 싶을 때 쓸 수 있는 스킬

* 쿼터 셀을 흩은 시나리오를 브라우저 여러 개로 동시에 돌림
* 오탐은 다시 돌려 확인한 뒤에만 보고함
* 결과는 PDF 보고서로 남음

## 무엇이 가능해졌나

- 통계표 수령 체크리스트를 손으로 하지 않아도 됩니다.
- 엑셀 수정요청서가 필요하면 기존 /웹테스트, PDF가 필요하면 /웹테스트-PDF 를 고르면 됩니다.

## 한번 써보세요

1. 채팅창에 이렇게 입력합니다.

```
/테이블검수 <설문지.docx> <테이블가이드.xlsx> <통계표.xlsx>
```

2. 같은 폴더에 검수 엑셀이 생깁니다.

## 주의할 점

- /웹테스트-PDF 는 실사 중인 설문에는 돌리지 않습니다(테스트 상태에서만).
