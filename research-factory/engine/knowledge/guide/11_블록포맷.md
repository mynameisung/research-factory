# 11. 제작가이드 블록 포맷 【업무 A】

`본문` 시트는 **슬라이드 1장 = 블록 1개**의 반복이다. 블록 사이는 빈 행 2줄.

---

## 1. 6줄 라벨 — 영문 고정, 병합셀 없음

```
Slide title
Sub title
Chart type
Base/Unit
Question/Reference
Data
```

이 6개가 원본이다 — `Basic_Set!A40:A45` 에 그대로 박혀 있다. 별칭 `Ment` 는 `Basic_Set!A5`.

> "오빠가 잡아줘야 될 건 이 6개의 행이거든요." (녹취 21:47)
> "이거 여기만 안 바꾸면 돼요." (19:21)

**라벨 문자열을 바꾸지 않는다.** 나머지(칸 위치·띄어쓰기·줄 수)는 전부 자유다.

---

## 2. 열 배치 — 파일마다 다르다. 상대 위치만 지킨다

| | 라벨 열 | 값 열 (V) | 행수식어 | 행 라벨 (V+1) | 전체 (V+2) | 배너 (V+3~) |
|---|---|---|---|---|---|---|
| **LG** (`본문_제작용`) | A | **B** | B | C | D | E~N |
| **SKEE** (`본문`) | B | **C** | C | D | E | F~N |
| **우리 템플릿** | B | **C** | C | D | E | F~N |

SKEE는 A열을 **섹션 인덱스**(1, 2, 2.1, 2.2, 3-a …)로 쓴다. 선택이다.

**불변식**
```
행수식어 열 == 블록 값 열 (V)
행 라벨 열  == V + 1
전체 열    == V + 2
배너 열    == V + 3 …
```

## 3. 블록 1개의 전체 모습 (실측: SKEE 본문 714~737행)

```
B714  Slide title          C714  1. 계약전 사전 서비스
B715  Sub title            C715  1) 계약전 사전 서비스 만족도
B716  Chart type           C716  전체 : +-세로막대 그래프
B717  Base/Unit            C717  [Base: 전체(n=28)/ Unit: %]
B718  Question/Reference   C718  Qu: 건설 프로젝트 추진 시 당사에서 제공한 계약 전 사전 서비스에 대해 만족하십니까?
B719  Data                 C719  (빈 문자열)
                           C720  계약전 사전 서비스 만족도는 82.1%(TOP2 기준)로 우수한 수준임      ← 멘트 1행
                           C721  소속별로 보면 SK플라즈마, 직위별로 보면 임원급의 …               ← 멘트 2행
      (빈 행)
                           E724 '전체'  F724 '소속'  I724 '직위'                                ← 배너 그룹 헤더
                           F725 'SK가스' G725 'SK IE&S' H725 'SK플라즈마' I725 '팀원' …          ← 배너 세부 헤더
                           D726 'Base for %'  E726 '(28)'  F726 '(9)' …
                           D727 '매우 불만족'   E727  3.571 …
                           D728 '불만족'        E728  0 …
                           D729 '보통'          E729 14.286 …
                           D730 '만족'          E730 53.571 …
                           D731 '매우 만족'      E731 28.571 …
                           D732 '      계'      E732 100 …
                           D733 '【BOT2】'       E733  3.571 …
                           D734 '【SoSo】'       E734 14.286 …
C735 '그래프 상단 Text'      D735 '【TOP2】'       E735 82.143 …
C736 '그래프 상단 Text'      D736 '[5점 평균]'     E736  4.036 …
      (빈 행 2줄)  →  다음 블록
```

### 멘트 위치
`Data` 라벨 **아래 행부터**, 라벨 없이 값 열에 이어 쓴다. 1행에 한 문장.

> "데이터 옆에다 씁니다." / "한 칸 아래에다가. 근데 그거 제작팀이 직접 하는 거라 위치는 진짜 상관없긴 해요." (24:21)
> "최대 두 줄?" — "세 줄 네 줄도 상관없긴 해요." (24:17)

관행은 **2줄**(전체값 1줄 + 배너 1줄). 요약 장표는 3줄까지 쓴다 (SKEE C163:C165).

### Question/Reference
항상 `Qu: ` 접두 + **설문지 원문 그대로**.
> "QA는 질문이에요. 이건 설문지에 있어요. 설문지에 있는 걸 그대로 넣으면 돼요." (23:58)

순위 문항은 설문지 문항 뒤에 통계표 꼬리표를 붙인다:
`Qu: 집에 로봇이 있다면, 어떤 상황에서 가장 도움을 받고 싶을 것 같나요?_1+2+3순위 (중복응답)`

주석용으로도 쓴다 (SKEE 실측): `* 소수 응답 생략` · `* 1+2+3순위 기준 10% 미만 제외`

### 데이터 영역
통계표의 해당 표를 **행 라벨 공백까지 그대로** 옮긴다.
- `Base for %` / `      계`(공백 6) / `【BOT2】` / `[5점 평균]` — 한 글자도 바꾸지 않는다
- 보기 라벨 `  4) …` 앞 공백 2칸 유지
- 값은 통계표 **표시값**(% 1자리 / 평균 2자리)
- 빈 셀은 매크로 `lovelySeoyeon` 으로 `-` 치환

## 4. 다단 슬라이드 — 가로로 반복한다

한 슬라이드에 패널이 여럿이면 `Chart type` / `Base/Unit` / 패널 제목 / 데이터를 **오른쪽으로 반복**한다.
라벨은 왼쪽에 한 번만 적는다.

실측 (LG 130~151행, 요약 슬라이드):
```
A130 Chart type   B130 전체 : 원그래프          I130 전체 : 가로 겹침 막대 그래프   N130 전체 : 가로 막대 그래프
A131 Base/Unit    B131 [Base: …]               I131 [Base: …]                  N131 [Base: …]
A133 Data         B134 <멘트>
                  B137 사람과 홈로봇의 관계 인식   I137 기대하는 도움 상황           N137 사용의 주체
                  B139 A1. …                   I139 A12. …                     N139 A14. …
                  C140 전체                     J140 1순위  K140 1+2+3순위
                  B142 Base for %  C142 (100)   I142 Base for %  J142 (100) K142 (100)
                  B143   2) 비서형  C143 37     I143   3) 더럽거나 위험한 일 …
```

세로로도 반복된다. 두 번째 줄 패널은 **라벨 없이** 값 열에 Chart type 문자열만 적는다:
```
B153 전체 : 가로 누적 100% 막대 그래프     I153 전체 : 가로 겹침 막대 그래프
B154 [Base: 전체(n=100)/ Unit: %]        I154 [Base: 전체(n=100)/ Unit: %]
```

SKEE는 2단(C / G~H)을 쓴다 — 좌: 척도 100% 3점막대, 우: 사유 가로막대.

패널 옆 빈 셀에 **레이아웃 지시**를 적는다: `1/3 공간만 만들어주세요` 등 → `guide/15`.

## 5. 구조 블록 (표지 · 목차 · 간지)

라벨 6줄은 그대로 두고 `Chart type` 칸에만 구분어를 적는다.

```
Slide title
Sub title
Chart type          표지
Base/Unit
Question/Reference
Data
```

**간지**는 Data 아래에 그 Part의 세부 목차를 나열한다 (SKEE 139~155행):
```
Slide title         Part Ⅱ. 요약 및 결론
Chart type
Base/Unit           간지                    ← SKEE는 Base/Unit 칸에 적었다. 위치는 자유
Data
                    1. 만족도
                    2. Pre-Operation
                    …
```

`목차(보고서용)!C1` 의 지시대로 **첫 페이지 목차에는 Part만, 간지에는 세부 목차**를 넣는다.

## 6. 조건부서식 — `그래프 상단 Text` 오타 검출기

`본문` 시트에 `cellIs equal "그래프 상단 Text"` → **빨간 글자** 조건부서식이 걸려 있다.
(LG 436개 / SKEE 296개 규칙. 우리 템플릿은 `A1:AN1048576` 한 개로 통합)

정확히 입력하면 글자가 빨개진다. **안 빨개지면 오타다.**

## 7. 제작팀 송부본

작업본에는 수식과 우리 작업용 시트(`_치트시트`·`_스니펫`)가 들어 있다.
송부 전에:
1. `_` 로 시작하는 시트를 **삭제**
2. 수식을 **값으로 평탄화** (LG 예시가 실제로 이 상태 — 수식 흔적이 거의 없다)
3. 매크로 `lovelySeoyeon` 으로 빈칸을 `-` 로 치환
4. `Cover` 의 `보고서 Title`(C4)·`제출일`(C6) 기입
5. `Cover` 의 `검수 실행` 실행 (RPA 애드인이 있는 PC에서)


## Question/Reference 에는 **질문만** 넣는다 (R-189)

이 칸에는 `Qu:` 문장 하나만 들어간다. 셋을 뺀다 —

| 빼는 것 | 예 | 어디로 |
|---|---|---|
| **각주** | `* 분모는 용도가 지정된 층의 합계이며…` | 전달 문서(연구원 확인 목록) |
| **`※` 기입 안내** | `※ 담당 회사가 한 곳인 경우: 첫 번째 행(1행)에만…` | 버린다 — 응답자용이라 제작팀이 그릴 것이 없다 |
| **매트릭스 소항목 접미** | `… | 계약 기간` | `Sub title` 이 이미 구분한다 |

근거는 하우스 예시 실측이다 — LG 75블록 · SKEE 69 · SH청안주 50 에서 **여러 줄 Qu 가 0건**이다.

> 각주를 셀에서 뺀다고 정보가 사라지는 것이 아니다. **자리를 옮기는 것**이다.
> 옮긴 곳을 사용자에게 반드시 알린다.

## 저베이스 표기는 넣지 않는다 (R-188)

`Base for %` 행의 별표(`(13*)`)와 `*Too small base(n<30)` 범례를 **제작가이드에 넣지 않는다.**

| 어디에 | 별표 | Too small |
|---|---:|---:|
| 통계표 원본 | 0건 | — |
| 하우스 제작가이드 4벌 (base 셀 2,886개) | **0건** | **0건** |
| 제작본·최종본 | 있음 | 있음 |

그 표기는 **제작 이후 단계에서 붙는다.** 우리만 별표를 달면 제작팀이 통계표와 대조할 때 「다른 값」으로 읽는다.

## 빈 칸은 `-` 로 메운다 (R-192)

표 데이터 칸의 빈 자리를 `-` 로 채운다(`build_guide --dash-empty`). 사내 매크로 `Sub lovelySeoyeon()` 이 하는 일과 같다 —
제작팀이 빈칸을 「값이 없음」인지 「적는 걸 잊었음」인지 구분하지 못한다.

하우스가 갈린다(SKEE 수백 개 · LG 0개). **조사마다 정하되 기본은 채우는 쪽**이다.

## 값은 원값, 자릿수는 서식 (R-191)

데이터 칸에 `14.3` 같은 **반올림 문자열을 담지 않는다.** 통계표 셀의 원값(`14.285714285714285`)을 **숫자로** 담고
표시 자릿수는 셀 서식(`###0.0`)이 정한다. 통계표가 그렇게 되어 있다.

- 문자열로 담으면 엑셀이 「텍스트로 저장된 숫자」로 잡아 합계·차트가 막힌다 (LG 예시는 float 이다)
- 반올림해서 담으면 제작팀이 다시 계산할 때 자릿수가 한 번 더 깎인다
- **반올림 방향**: 엑셀은 0.5 를 올리고 파이썬 f-string 은 짝수로 보낸다. 검수기는 round-half-up 을 쓴다
- 자릿수를 통일하지 않는다 — 백분율 1자리 · 평균 2자리 · 통계표가 2자리로 준 표는 2자리
