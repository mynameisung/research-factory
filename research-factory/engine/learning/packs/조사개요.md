### R-011 · 표1(응답자 특성)만 행 라벨이 2열이다
- 분류: 통계표 / 레이아웃
- 규칙: 일반 표는 행 라벨 1열(A) + 전체(B) + 배너(C~). 표1만 행 라벨 2열(A=특성군, B=보기) + 전체(C) + 배너(D~). 파서에 오프셋 분기가 필요하다.
- 근거: tables.json#표1 `label_cols:[0,1] banner_col_start:2` vs 나머지 `label_cols:[0] banner_col_start:1` · 녹취 20:30
- 신뢰도: 확정
- 적용: 파서
- 이력: 2026-08-21 신규

### R-124 · 클라이언트 로고는 비율을 바꾸지 않고 끼운다
- 분류: guide / 서식
- 규칙: Cover 로고를 갈아 끼울 때 **앵커 상자의 높이를 유지하고 너비만 새 이미지 비율로 다시 계산**한다. 상자에 맞춰 늘이지 않는다.
- 근거: 에스원 CI 규정 원문 — 「로고타입은 … **글자의 꼴, 굵기, 비례, 자간 등의 임의 변경을 금합니다.** 색상은 PANTONE 286C나 검정색으로 …」 (<https://www.s1.co.kr/company/introduction/ci>). 대부분의 기업 CI 가 같은 조항을 둔다.
- 실측: LG 상자 1825216×637475(비율 2.863) ↔ 에스원 기본형 532×201(비율 2.647). 그대로 끼우면 8% 가로 늘어남 = 규정 위반.
- 신뢰도: 확정
- 적용: `build_guide.swap_logo()`
- 이력: 2026-08-22 신규

### R-127 · Cover 의 프로젝트 값은 빌드 인자로 채운다
- 분류: guide / 서식
- 규칙: `Cover!C4`(보고서 Title)·`C6`(제출일)은 `--title`·`--date` 로 채운다. 비워 두면 예시에서 물려받은 값이 남거나(LG: `홈로봇 조사`) 빈칸으로 제출된다.
- 실측: 테마글꼴·마스터·차트색(`C14/C15/C17/C19`)은 템플릿이 이미 중립값(맑은 고딕 / Arial / 기본 마스터(Blue) / 기본 자사색(Blue))이라 손대지 않는다. 클라이언트 지정 테마가 오면 그때 바꾼다.
- 배너 너비(`C21/C22`)는 LG·SKEE **둘 다 비어 있다** — 채우지 않는 칸이다.
- 신뢰도: 확정
- 적용: `build_guide.py`
- 이력: 2026-08-22 신규
