## 4. 고치지 않기로 한 것

### 4-a. MAP-010 (동일 문항코드 → 복수 본문 슬라이드) — 구현하지 않음

검수관 제안은 "동일 문항코드가 본문 2장으로 분할되는 케이스를 지원하라" 였다. 근거를 확인한 결과
**분할이 아니라 미제작 클론**이었다.

- `s81 / s82` (`C2-1/C2-2/C2-3`) 두 장이 제목·Qu·Base·카테고리·계열값까지 **완전 동일**
- `s83 / s84` (`C3`), `s85 / s86` (`C3-1/…`), `s87 / s88` (`C4`) 는 차트 계열값이 전부
  `1+2+3순위 = 50.0`, `1순위 = 25.0` **더미**이고 표 라벨이 빈칸
- `s83` 의 카테고리는 `s80 (C2)` 의 시나리오 순서를 그대로 복사한 것이다
- 가이드에는 해당 문항코드 블록이 **각 1개**뿐이다(표 1개 · `Base for %` 1행). 분할 지시 신호가 없다
- 분할이 의도였다면 `C2-1/C2-2/C2-3` 은 3장이어야 하는데 2장이다

없는 신호로 슬라이드를 복제하는 규칙을 만들면 다음 프로젝트에서 중복 장표를 양산한다.
→ `GOLDEN_SET.md §5-g-1` 결함 등재. 중복 문항코드는 **첫 장만** 채점 모수에 넣는다.

> 검수관이 짚은 함정 — "예측 79건과 정답 79장의 개수만 우연히 같다" — 은 그대로 유효하다.
> MAP 은 총량이 아니라 **키 단위**로 세야 한다. 채점기를 그렇게 고쳤다.

### 4-b. SORT-SRC (C1 vs A4 데이터 소스) — 예측이 옳다

`s93 (C1)` 의 차트 계열값 `[33.0, 24.0, 24.0, 19.0]` 이 `s90 (A4)` 와 완전히 같고, 카테고리도 A4 의
라벨(`기능형 로봇` — `로봇` 접미)을 그대로 쓴다. 표 본문 라벨은 전부 빈칸이다.
가이드 `C1` 블록은 값 `[35, 27, 27, 11]`, 라벨 `가전형 / 기능형 / 공간형 / 인간형`(접미 없음)으로 **다른 데이터**다.
→ 사전(A4)/사후(C1) 슬라이드를 복제해 두고 갱신하지 않은 것. `GOLDEN_SET.md §5-g-2` 등재, SORT 렌즈에서 제외.

### 4-c. 멘트 렌즈 — G1 에서 채점하지 않는다

정답 결손(LG 본문 79/79 `top_ment` 공백, 덱 99장 중 멘트성 문장은 s8 1장)과 예측 결손(생성 미구현)이
겹쳐 빈칸-빈칸 공허 일치 74/74 가 났다. 이걸 100% 로 보고하면 미구현이 만점으로 위장된다.

- 렌즈 스코프를 `chart_rules.yaml#scoring_hygiene.lens_scope` 에 명시 — MENT-* 는 G1 채점 제외, G2 에서만
- 공허 일치 금지를 `rules.yaml V-090` 으로 검사 항목화
- 예측기 쪽 결손은 별도로 남긴다 — 가이드 원본에 멘트 보유 블록이 9개(25줄) 있는데 0줄을 냈다.
  이번 라운드에서는 **`ment: null` + `ment_status`** 로 "미구현" 임을 명시만 하고 생성기는 만들지 않았다(R-088).
  멘트 생성은 이번 교정의 범위가 아니고, 억지로 붙이면 검증 표본이 없는 채로 환각 위험만 들어온다.

### 4-d. RC-2 의 진단은 수정해서 채택했다

검수관은 "`is_ranking` 이 보기 라벨의 선행 서수를 근거로 삼는다" 고 했으나, 실제 코드는 **헤더 셀 문자열
부분일치**를 쓰고 있었다. 오탐 경로가 다르다 — 교차표 머리글 `C4 1+2+3순위` × `C2 1순위` 가 걸린 것이다.
증상(요약 s10 오탐)은 같으므로 규칙은 채택하되 판정 기준을 **배너 라벨 완전일치**로 명문화했다(R-087).
이 수정은 본문 게이트와 독립적으로 동작한다(이중 방어).

### 4-e. 차트타입 규칙은 손대지 않았다

TYPE 은 교정 전에 이미 75/75 였다. `decision_table` 의 판정 조건(`when`)은 한 글자도 바꾸지 않았고,
`then` 에 축·상단행 정보만 덧붙였다. 교정 후에도 계열별 전승(23/23 · 11/11 · 36/36 · 5/5)을 재확인했다.
